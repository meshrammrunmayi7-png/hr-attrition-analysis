# HR Attrition Analysis Dashboard
Python • SQL • Tableau

## Overview
This project analyzes employee attrition patterns using Python, SQL, and Tableau. The objective was to identify trends related to employee turnover and build an interactive dashboard to support retention-focused decision-making.

## Tools Used
- Python (Pandas) – data cleaning and preparation
- MySQL – exploratory and business analysis queries
- Tableau Public – dashboard creation and visualization
- GitHub – project documentation and portfolio hosting

## Business Problem
Employee attrition can increase hiring costs, reduce productivity, and impact team performance. This project explores which employee groups are more likely to leave and what factors may be linked to attrition.

## Project Workflow
1. Cleaned and prepared raw HR data using Python  
2. Performed SQL analysis on attrition trends  
3. Built an interactive Tableau dashboard with filters and actions  
4. Published project assets to GitHub

## Key Insights
- Overall attrition rate: **16.1%**
- Sales had the highest attrition rate among departments
- Lower job satisfaction was linked with higher attrition
- Employees with 0–2 years tenure showed highest attrition
- Lower work-life balance levels had higher attrition rates
- Employees who left had lower average income than retained employees

## Recommendations

* Focus retention efforts on departments and tenure groups with higher attrition risk through targeted engagement and career development initiatives.
* Strengthen employee satisfaction and work-life balance programs, as lower scores were associated with higher attrition.
* Use regular attrition monitoring dashboards to identify emerging turnover patterns early and support proactive HR decision-making.
